# Assignments & Experiments

This section collects selected assignments, computational experiments and technical exercises developed during my studies in Digital Humanities and Computational Linguistics.

Rather than simple coursework, these projects represent exploratory work on Natural Language Processing, machine learning, linguistic modeling, semantic analysis and data-driven methods for language research.

The experiments focus on topics such as:

- sentiment classification
- topic classification
- part-of-speech tagging
- Hidden Markov Models
- clustering evaluation
- semantic embeddings
- question answering
- natural language and logic

Most projects were developed using Python, NLTK, NumPy, scikit-learn, Jupyter Notebooks and statistical analysis tools.

The goal of this section is to document both technical skills and the process of experimenting with computational approaches to language and textual data.
